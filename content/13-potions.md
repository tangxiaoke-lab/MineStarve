# 药水酿造

用炼药台将水瓶炼成粗制药水，再加入不同材料制成饮用或喷溅药水。

## 炼药台与基础药水

炼药台需要石砖 ×3、金块 ×2、红宝石 ×1，在炼金引擎附近制作。1 个热腺提供 20 批燃料，空闲时不会消耗；每批酿造约 20 秒，一份材料最多同时处理 3 瓶。

在科学机器附近用 1 个月亮碎片制作 3 个玻璃瓶；玻璃瓶加 1 块冰制成水瓶。把蕨叶加入水瓶，得到粗制药水。将下表材料加入粗制药水，即可制成对应药水。

| 材料 | 药水 | 主要效果 |
| --- | --- | --- |
| 西瓜 | 治疗 | 立即恢复 20 点生命 |
| 海象牙 | 迅捷 | 提高移动速度 |
| 下界石英 | 力量 | 提高造成的伤害 |
| 怪物肉 | 伤害 | 立即造成 30 点伤害 |
| 红蘑菇 | 剧毒 | 周期性造成伤害，不会因此将生命降到 1 以下 |
| 蝴蝶翅膀 | 再生 | 持续恢复生命 |
| 龙鳞 | 抗火 | 获得抗火效果 |
| 鼹鼠 | 夜视 | 获得夜视效果 |
| 腐烂食物 | 虚弱 | 降低造成的伤害 |
| 蜗牛壳碎片 | 神龟 | 降低受伤，同时减慢移动 |
| 邪天翁羽毛 | 水肺 | 获得水下呼吸效果 |
| 曼德拉草 | 幸运 | 提高幸运值 |

## 延长、强化与喷溅

给适用的一级药水加入红石可将持续时间延长一倍；加入月亮碎片可制成适用的 II 级药水。延长版与 II 级版是不同的加工路线，不能在同一瓶上叠加。给可饮用药水加入火药可变为喷溅药水，作用范围约为 4。

炼药台还能把木炭加工成煤炭，每份成功率为 33%。该过程同样消耗一批燃料；失败也会消耗木炭。

> 即时治疗与即时伤害没有持续时间；并非所有药水都有延长版或 II 级版。
