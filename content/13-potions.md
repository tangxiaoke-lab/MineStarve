# 药水酿造

用炼药台将水瓶炼成粗制药水，再加入不同材料制成饮用或喷溅药水。

## 炼药台与基础药水

炼药台需要石砖 ×3、金块 ×2、红宝石 ×1，在炼金引擎附近制作。1 个热腺提供 20 批燃料，空闲时不会消耗；每批酿造约 20 秒，一份材料最多同时处理 3 瓶。

从空瓶到基础药水的每一步如下；一份酿造材料最多同时作用于 3 瓶。

| 产物 | 原料 | 制作方式 |
| --- | --- | --- |
| 玻璃瓶 ×3 | 月亮碎片 ×1 | 科学机器附近制作 |
| 水瓶 | 玻璃瓶 ×1＋冰 ×1 | 无需科技制作 |
| 粗制药水 | 水瓶＋蕨叶 | 放入炼药台酿造 |

将下表材料加入炼药台中的粗制药水，即可制成对应药水。

| 材料 | 药水 | 主要效果 |
| --- | --- | --- |
| 西瓜 | 治疗 | 立即恢复 20 点生命 |
| 海象牙 | 迅捷 | 提高移动速度 |
| 下界石英 | 力量 | 提高造成的伤害 |
| 怪物肉 | 伤害 | 立即造成 30 点伤害 |
| 红蘑菇 | 剧毒 | 周期性造成伤害，不会因此将生命降到 1 以下 |
| 蝴蝶翅膀 | 再生 | 持续恢复生命 |
| 龙鳞 | 抗火 | 获得抗火效果 |
| 鼹鼠 | 夜视 | 获得夜视效果 |
| 腐烂食物 | 虚弱 | 降低造成的伤害 |
| 蜗牛壳碎片 | 神龟 | 降低受伤，同时减慢移动 |
| 邪天翁羽毛 | 水肺 | 获得水下呼吸效果 |
| 曼德拉草 | 幸运 | 提高幸运值 |

## 延长、强化与喷溅

| 酿造材料 | 投入的药水 | 产物 |
| --- | --- | --- |
| 红石 | 一级迅捷、力量、剧毒、再生、抗火、夜视、虚弱、神龟、水肺或幸运药水 | 对应延长版，持续时间加倍 |
| 月亮碎片 | 一级迅捷、力量、伤害、剧毒、再生、神龟或幸运药水 | 对应 II 级药水 |
| 火药 | 任意可饮用药水，包括粗制药水和已延长、强化的成品 | 对应喷溅药水，作用范围约为 4 |

延长版与 II 级版是不同的加工路线，不能在同一瓶上叠加。喷溅药水也可按相同材料继续酿造适用的配方。

| 其他酿造 | 产物与消耗 |
| --- | --- |
| 木炭放入炼药台 | 有 33% 概率得到煤炭；每次消耗一批燃料，失败也会消耗木炭 |

> 即时治疗与即时伤害没有持续时间；并非所有药水都有延长版或 II 级版。
