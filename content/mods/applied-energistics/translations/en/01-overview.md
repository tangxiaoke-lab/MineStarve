# About the mod

Applied Energistics adds unified storage and automation tools to Don't Starve Together. Storage Terminals provide shared access to containers, while ME Storage Cells expand digital storage.

## Main features

| Feature | Description |
| --- | --- |
| Unified storage access | Storage Terminals connect nearby available containers for viewing, depositing and withdrawing items. |
| Digital storage | ME Drives read installed ME Storage Cells, which offer different capacities. |
| Wireless access | Bind a Wireless Storage Terminal to a fixed terminal to access its storage remotely. |
| Expansion cards | Crafting Terminal, Pattern Terminal, Distance and Acceleration Cards extend terminal functions. |
| Item transfer | Input and Output Bus Cards exchange items on matching channels. Outputs support a whitelist. |
| Automation patterns | Configure a Blank Pattern with an automation recipe, then install the pattern on a supported target. |

## Mod information

The author is Tangxiaoke and the version is 26.09.05.1. The in-game English name is [DST]Applied Energistics. Both the server and clients need the mod installed.

The mod draws inspiration from Applied Energistics 2 and WIGFRID's Simple Storage mod.
