# Expansion cards and automation

Expansion cards add crafting, pattern, remote access and automation functions. Bus cards transfer items between containers.

## Four expansion cards

| Card | Function |
| --- | --- |
| Crafting Terminal Card | Enables crafting quantities and shares the technology scanned by the terminal while it is in use. |
| Pattern Terminal Card | Configures automation patterns. |
| Distance Card | Allows cross-world access to the terminal. |
| Acceleration Card | Speeds up terminal automation jobs. |

## Patterns

A Blank Pattern can be configured with an automation recipe. Use Install Pattern to install a configured pattern on a supported automation target. A blank pattern without a recipe cannot be installed directly.

## Input and output buses

| Card | Direction and rules |
| --- | --- |
| Output Bus Card | Sends whitelisted items from its container to Input Bus Cards on the same channel. |
| Input Bus Card | Receives items from Output Bus Cards on the same channel. |

Bus transfers require matching channels. The output whitelist determines which items are sent.
