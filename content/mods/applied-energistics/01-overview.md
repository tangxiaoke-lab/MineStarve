# 模组介绍

《应用能源》为饥荒联机版加入统一存储与自动化工具，通过存储终端集中访问容器，并使用 ME 存储元件扩展数字存储。

## 主要功能

| 功能 | 内容 |
| --- | --- |
| 统一存取 | 存储终端把附近可用容器连接起来，集中查看和存取物品。 |
| 数字存储 | ME 驱动器读取安装的 ME 存储元件，提供不同容量的物品存储。 |
| 无线访问 | 无线存储终端绑定固定终端后，可远程访问对应存储。 |
| 功能扩展 | 合成终端卡、样板终端卡、距离卡和加速卡用于扩展终端功能。 |
| 物品传输 | 输入与输出总线卡通过同一频道收发物品，输出支持白名单。 |
| 自动化样板 | 使用空白样板记录自动化配方，再将配置好的样板安装到支持的目标。 |

## 模组信息

模组作者为唐小可，版本为 26.09.05.1。游戏中名称为“[DST]应用能源”，英文名称为“[DST]Applied Energistics”。客户端与服务器都需要安装此模组。

本模组参考 Applied Energistics 2 以及 WIGFRID 的《简易存储》模组。
