# 功能卡与自动化

功能卡扩展终端的制作、样板、远程访问和自动化能力；总线卡用于容器之间的物品传输。

## 四种功能卡

| 卡片 | 功能 |
| --- | --- |
| 合成终端卡 | 允许配置制作数量，并在使用终端时共享终端读取到的科技。 |
| 样板终端卡 | 用于配置自动化样板。 |
| 距离卡 | 允许跨世界访问该终端。 |
| 加速卡 | 加快终端自动化任务。 |

## 样板

空白样板可以写入自动化配方。配置好的样板可通过“安装样板”动作安装到支持的自动化目标；尚未写入配方的空白样板无法直接安装。

## 输入与输出总线

| 卡片 | 方向与规则 |
| --- | --- |
| 输出总线卡 | 将所在容器内符合白名单的物品发送到同频道的输入总线。 |
| 输入总线卡 | 接收同频道输出总线传来的物品。 |

总线传输以频道匹配为前提。输出卡的白名单用于决定发送哪些物品。
